## How to contribute

1. Fork the repository and create a feature branch.
2. Make your changes with clear, focused commits.
3. Ensure tests pass and add tests where appropriate.
4. Open a pull request describing the change and its motivation.

## Code style

- Keep changes small and focused.
- Follow the existing conventions in the codebase.
- Include or update documentation when behavior changes.

## Reporting issues

Please use the issue tracker to report bugs or request features. Do not include
secrets, credentials, or confidential information in issues or pull requests.
